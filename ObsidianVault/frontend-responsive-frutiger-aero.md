# Frontend — Responsive + Frutiger Aero

## Decision

All frontend pages and components must be:

1. **100% responsive** — desktop and mobile, no exceptions.
2. **Frutiger Aero aesthetic** — glossy surfaces, translucent/glass effects, soft gradients, rounded corners, nature-inspired color accents, clean sans-serif typography, depth via layered translucency.

## Why

Owner's explicit design requirement (2026-07-31). Applies to every screen built from now on.

## How to apply

- Every layout must use responsive patterns (flex/grid, relative units, breakpoints via Tamagui media queries).
- Visual style: glass/frosted backgrounds, soft shadows, gradient accents, rounded corners, light/airy feel.
- Test on both desktop and mobile viewports before considering any page done.
