# Catalog seed data

Backing files for `apps/backend/cmd/catalogsync` (see that command's doc
comment) and `db/migrations/00017_seed_catalog_*.sql` onwards. Full workflow
in `ObsidianVault/catalog-seed-from-prod.md`.

**Committed** (hand/Claude-authored, reviewed in the diff):
- `translations.json` - every non-source-locale translation this tool has
  generated so far, keyed by kind → name → locale. This is the actual
  content a generated migration writes; edit it, don't hand-edit the
  migration.
- `sources.json` - the confirmed source locale for each character row
  (stands are always es-ES, devil fruits always en-GB, hard-coded).

**Never committed** (`.gitignore`d - regenerated by the tool, not a source
of truth):
- `snapshot.json` - the last prod dump (`catalogsync dump`).
- `pending.json` - what `catalogsync plan` found still needs translating.
- `sources.suggested.json` - `plan`'s best guess at an unconfirmed
  character's source locale, for review before merging into `sources.json`.

## Running it

```
make catalog-dump-docker      # needs SOURCE_DATABASE_URL (see deployments/README.md's DB tunnel)
make catalog-plan-docker      # writes pending.json, or sources.suggested.json if a character's source locale isn't confirmed yet
# ... translate pending.json's entries into translations.json ...
make catalog-plan-docker      # re-run until it reports nothing pending
make catalog-generate-docker  # writes the next db/migrations/NNNNN_seed_catalog_*.sql
```
